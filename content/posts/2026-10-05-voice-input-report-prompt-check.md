移動中にスマホの音声入力で状況報告を喋って、そのままAIに「整えて」と頼んだら、口癖は消えたのに結論が最後まで出てこない文章が返ってきて、結局自分で並び替える羽目になったことはありませんか。私も先月、電車の中でそれをやって、送信前に結局全文を読み直すことになりました。

この記事を読むと、音声入力で喋った雑談っぽいメモを、AIへの指示だけで「結論が先頭に来る報告文」まで一気に仕上げる、指示の具体性の上げ方が分かります。

## 検証: 「整えて」だけで報告文になるか

音声入力で喋ったことを想定した、次のようなメモを用意しました。

```
えーっと、今日なんですけど、A社との打ち合わせ、一応終わったんですけど、なんか先方の予算がまだ確定してないみたいで、ちょっと来週またミーティングすることになりました。あ、あと見積書の件は、えー、金曜までに出してほしいって言われたので、それも対応しないといけないです。
```

これに対して、指示の具体性を3段階に分けてAIに渡し、出力を比較しました。

### 指示1: 「整えて」だけ（所要時間0分・コピペだけ）

```
次の文章を整えてください。

（ここに音声入力したメモを貼る）
```

返ってきたのは、口癖は消えて文法も整った文章でした。ただし話した順番のまま、「打ち合わせが終わった→予算が未確定→来週また打ち合わせ→見積書は金曜まで」という構成を引き継いでいて、一番伝えたい「来週また打ち合わせになった」という結論は文章の中ほどに埋もれたままでした。報告として読むには、結局もう一度自分で要点を拾い直す必要がありました。

### 指示2: 口癖削除＋結論を先頭に指定（所要時間1分）

```
次の文章から「えーっと」「なんか」「一応」のような口癖を削除し、
結論を最初の一文にまとめてから、全体を整えてください。

（ここに音声入力したメモを貼る）
```

結論（来週また打ち合わせになったこと）が先頭に来るようになりました。ただし文体は中途半端な丁寧語止まりで、上司に送るにはもう一段階、敬語を整える手間が残りました。

### 指示3: 役割＋型＋文数を指定（所要時間1分）

```
次の内容を、上司への報告メールとして敬語で、
結論→理由→次の対応の順に3文以内でまとめてください。

（ここに音声入力したメモを貼る）
```

「本日のA社との打ち合わせは終了いたしましたが、来週改めてミーティングを行うことになりました。先方の予算がまだ確定していないためです。また、見積書につきましては金曜までに提出するよう依頼されておりますので、別途対応いたします。」という、そのまま送れる3文の報告文になりました。

## つまずきポイント

**効かなかったこと**: 「整えて」というざっくりした指示は、口癖や言い回しの乱れは掃除してくれますが、話した順番そのものを並び替えて結論を先頭に出す、という構成の変更までは期待できませんでした。曖昧な指示は「掃除」はしてくれても「編集」はしてくれない、という感触です。

もう1点、音声入力はそもそも周囲の雑音や早口で誤変換が起きやすいので、金額や日付など数字が絡む部分は、整形後に必ず元の音声入力の文字起こしと見比べてください。今回の検証はこのメモ1本・1回の試行のみなので、他の内容や長さでも同じ傾向になるとは言い切れません。

## まとめ

まず今日は、次に音声入力で何かメモを喋ったら、「整えて」だけで終わらせず、指示3の「役割＋結論→理由→次の対応＋文数」をそのまま貼ってみてください。口癖を消すだけでなく、結論が先頭に来るところまで一気に仕上がります。
