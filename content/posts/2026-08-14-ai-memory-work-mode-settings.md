先週、AIに今週の会議メモを3行で要約してもらったら、先月相談していた転職の話を勝手に踏まえた一言が混ざってきて焦りました。仕事の依頼のはずが、AIの記憶がプライベートの相談を引きずっていたんです。

この記事を読むと、ChatGPT・Claude・Geminiそれぞれの記憶機能の仕組みの違いがわかり、仕事用のチャットにプライベートな話題を混ぜ込ませない3つの設定ができるようになります。

## 今日やること: 3つのAIで「覚え方」がそもそも違う

まず前提として、3社は記憶の効き方が違います。ChatGPTはデフォルトでメモリがオンになっていて、数か月分の会話から個人的な情報を自動的に拾い、関連しそうな場面で自動的に呼び出す設計です。Geminiも「アクティビティの保存」がオンだと過去チャットを踏まえてパーソナライズが働き、18歳以上のアカウントではこれが初期設定でオンになっています。Claudeだけは設計が逆で、記憶機能自体はあっても、こちらが明示的に「これまでの話を踏まえて」と参照を促さない限り、自動では持ち出しません。

### 手順1: ChatGPTは「パーソナライズ」で記憶を仕事用に絞る

設定 → パーソナライズ → メモリ、と進むと、記憶している内容を1件ずつ確認・削除できる画面があります。まずここでプライベートな相談だけを消します。全部を毎回消すのが面倒な場合は、カスタム指示（Custom Instructions）に次の一文を足しておくと、記憶を残したまま混入を抑えられます。

```
仕事の依頼をするときは、過去に話した個人的な相談内容（転職・体調・家族の話など）を
要約や提案に含めないでください。今回渡した内容だけを対象にしてください。
```

### 手順2: Geminiは「Personal Intelligence」のメモリだけを切る

Web版はメニューの「設定とヘルプ」→「パーソナライズ設定」→メモリーをオフ、アプリ版はプロフィールアイコン→「Personal Intelligence」→Memoryのトグルをオフにします。注意点が1つあり、メモリーをオフにしても過去の会話履歴そのものは消えないので、混ぜたくない相談内容が残っている場合はGeminiアプリのアクティビティから履歴も別途削除する必要があります。

### 手順3: Claudeは「呼び出さなければ使われない」設計を逆手に取る

Claudeは記憶をオンにしていても、参照を促さなければ自動的には持ち出しません。仕事用チャットでは基本的に何もしなくて大丈夫ですが、念のため確実にしたい場合はチャットの冒頭に次の一文を置きます。

```
このチャットでは、過去の会話や記憶を参照せず、今回の指示だけをもとに回答してください。
```

### 実際に確認したこと

ChatGPTのメモリをオンにしたまま「先月、転職を迷っていると相談していた」という文脈を作った後、無関係な会議メモの要約を頼んだところ、要約の最後に「最近悩まれていることも踏まえて」といった一言が付け足され、依頼していない気遣いが混ざりました。同じ流れをGeminiでも試すと、直接的な言及こそなかったものの、提案の口調が心配するようなトーンに変わりました。Claudeでは、過去の相談内容を明示的に参照するよう頼まない限り、同じ現象は起きませんでした。

## つまずきポイント

**1つ目は、効かなかったことです。** 「今回は仕事の話だけにしてください」と会話の中で毎回念を押しても、一度記憶された情報自体は消えないため、翌日の別の会話でまた顔を出すことがありました。記憶を本当に切り離したいなら、その場の念押しではなく、設定画面から個別に削除するかメモリ自体をオフにする必要があります。

**2つ目は、メモリを全部オフにする副作用です。** オフにすると、前に伝えた社内の用語や好みの文体まで毎回忘れてしまい、かえって仕事の指示が長くなる場面がありました。プライベートは混ぜたくないが仕事の定型情報は覚えていてほしい、という場合は、全部オフにするより手順1のカスタム指示で線引きする方が現実的でした。

## まとめ・今日これだけ

AIのメモリをオンにしたまま使っている人は、まず設定画面を開いて記憶の中身を1回見るところから始めてください。プライベートの相談が仕事の依頼に混ざっていないか、確認するだけでも今日の一歩目になります。
