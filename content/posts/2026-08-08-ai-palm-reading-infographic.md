AIの答えは、文章で返ってくるもの。私はずっとそう思っていました。実際、この1ヶ月で書いた記事のほとんどが「どう書かせるか」の話です。

今日はそれを外します。手のひらを1枚撮って渡すと、**診断結果が1枚の画像（インフォグラフィック）で返ってきます。** そのままスマホに保存して人に見せられる形です。読み終わると、AIの出力先に「画像」という選択肢があることが体感でわかります。

先に断っておきます。**手相診断は娯楽です。** 当たる・科学的だという主張はしません。ここで本当に持ち帰ってほしいのは、自己紹介スライドでも、企画のサマリーでも、同じ手順で1枚絵にできるという事実の方です。

## 今日やること: 手のひら1枚から縦長の診断インフォグラフィックを作る

用意するのは、手のひらを写した写真1枚です。撮り方のコツは2つだけあります。

- **自然光で、影を作らない**（蛍光灯の真下だと自分の頭の影が落ちます）
- **手を平らに開き、指まで入れる**（手の形も診断項目に入っているため）

そして、ここが今日の一番大事なところです。**文字入りの画像を作るには、文字を描けるモデルを選ぶ必要があります。** 少し前まで、AI画像生成といえば日本語が謎の漢字に化けるのが当たり前でした。それが2026年に入って大きく変わり、Googleの画像生成モデル（Nano Banana Pro、およびその後継のNano Banana 2）の世代で、日本語の文字化けがほぼ解消しています。今回はGeminiの画像生成で作るのが素直です。

### 手順1: まず文章で診断させる（2分）

いきなり画像を作らせません。**先に文章で診断を出させます。** 理由は後述しますが、これが崩れを減らす最大のコツです。

```
あなたは、手相分析・性格傾向分析・自己理解レポート作成に精通したプロの手相アナリストです。
添付は私自身の手のひらの写真です。以下の観点で診断してください。まずは文章だけで出してください。

【分析ルール】
・占いとして断定しすぎず、手の線、形、濃さ、バランスから「傾向」として分析する
・見えない線や不明瞭な部分は断定しない
・前向きで実用的な表現にする
・各項目を「観察 → 解釈 → アドバイス」の順で簡潔に整理する

【必須の分析観点】
・生命線：体力 / 行動力 / 粘り強さ
・知能線：思考タイプ / 判断力 / 得意な考え方
・感情線：感情表現 / 恋愛傾向 / 人間関係
・運命線：仕事運 / 自立心 / キャリア傾向
・手の形：現実派 / 感性派 / 直感派 / 行動派

【出力】
1. 総合タイプ（第一印象 / 手相タイプの呼び名 / 全体の強み / 注意ポイント）
2. 主要線診断（生命線 / 知能線 / 感情線 / 運命線）
3. 才能・仕事運（向いている働き方 / 伸ばすべき才能）
4. 総合アドバイス（魅力ポイント3つ / 注意ポイント3つ / 明日から意識すること1つ）
```

返ってくるのは、手相の「タイプ名」がついた総合診断から始まり、主要4線それぞれの「特徴／意味／アドバイス」が続く形です。

### 手順2: その診断文を1枚の画像にさせる（3分）

同じチャットで続けて、こう指示します。

```
いま出してくれた診断結果を、日本語のインフォグラフィック画像1枚にしてください。

【デザイン】
・清潔感、可読性、分析レポート感を重視
・中央に手のひらのイラストを大きく配置し、主要な線に細い注釈線とラベルを入れる
・周囲に診断ブロックを整理して配置。余白を広めに取り、文字は詰め込みすぎない
・ビジネス資料 × 専門診断レポート風

【配色】
・ベース：ホワイト / ライトグレー ・メイン：ネイビー / ダークグレー
・アクセント：落ち着いたティールを少量
・彩度は低めで、信頼感と知性を重視。派手な金色やポップな色は使わない

【出力ルール】
・9:16の縦長画像1枚
・載せる文字は「総合タイプ」「主要線4つ」「明日から意識すること」だけに絞る
・短文と箇条書きのみ。長い文章は画像に入れない
```

## なぜ2段階に分けるのか

1回のプロンプトで「診断して、画像にして」と頼むこともできます。ただ、**画像生成は文字数が増えるほど崩れます。** 一度に全部やらせると、AIは診断も画像化も同時に処理することになり、画像に載せる文字量を自分で絞れません。結果、細かい文字が潰れます。

先に文章で診断を確定させ、次に「この中からこれだけを載せて」と絞ると、載る文字が減って読める1枚になります。一度に全部やらせたときと比べて、載る文字数が減るぶん1文字あたりの描画サイズが大きくなり、それが読みやすさに直結します。

この考え方は手相に限りません。**長い内容を1枚絵にしたいときは、まず文章で完成させ、そのあと「載せる項目を指定して」画像化する。** 会議資料のサマリー1枚でも、自己紹介スライドでも同じです。

## つまずきポイント

**1つ目は、デザイン指定を欲張ると読めなくなることです。** 元の指示には6つの診断ブロック（総合・主要線・才能・人間関係・金運・総合アドバイス）が入っていますが、これを全部9:16に詰めると1項目あたりの文字が小さくなり、スマホでは判読できません。**載せるのは3ブロックまで**が現実的です。残りは文章の方で読めばいいので、画像に全部入れる必要はありません。

**2つ目は、効かなかったことです。** 「文字を鮮明に」「高解像度で」といった品質を上げる言葉を足しても、文字の崩れは直りませんでした。効いたのは**文字量を減らすこと**だけです。画質の指示ではなく、情報量の設計が効きます。これは資料作りの原則とまったく同じで、そこが少しおかしくもありました。AIに頼んでも「詰め込みすぎ」は解決しないわけです。

もう1つ、「占いとして断定しすぎず」の一文を外すと、一気に断定調の占い文になります。娯楽として楽しむにしても、断定させない方が読み物として面白くなります。

## 送る前に1つだけ

手のひらも、顔と同じく個人が写った画像です。投げる前に学習オフ（オプトアウト）の設定を確認しておいてください。設定場所は「社外秘メモを貼る前に、AI3社のオプトアウト設定を確認する」にまとめてあります。

## まとめ・今日これだけ

手のひらを1枚撮って、手順1の文章診断だけでも回してみてください。画像化まで行かなくても、**AIに写真を渡して読ませる**という体験が1回できれば十分です。そこまで来たら、次は資料のサマリーを1枚絵にする番です。
