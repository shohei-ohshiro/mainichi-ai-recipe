08-09の記事で「AIに5人の会議を演じさせて企画を殴らせる」プロンプトを紹介しました。効果はあったものの、5人分の設定を書くのが正直めんどうで、ちょっとしたメール1本の送信前チェックには重すぎると感じていました。

この記事を読むと、5人を3人に減らした軽量版で、送る前チェックが3分で終わるようになります。あわせて、軽くした分だけ見逃しが増える落とし穴も分かります。

## 結論

「一番厳しい上司」「一番優しい先輩」「一番めんどくさい取引先」の3人だけに絞れば、大きな意思決定でなく**送る前の最終チェック**には十分です。ただし数字の整合性チェックだけは別に必要でした。

## レシピ本体（所要時間3分）

1. 送る予定のメールや文章の下書きを用意します。
2. 次のプロンプトに下書きを貼って実行します。3人が1つずつ指摘を返します。

```
あなたは3人を演じてください。私はこれから送るメールの下書きを1つ貼ります。
3人それぞれの立場から、送る前に直すべき点を1つずつ指摘してください。

【役1】一番厳しい上司：守るもの＝会社の利益と、対外的に舐められないこと
【役2】一番優しい先輩：守るもの＝相手との長期的な関係
【役3】一番めんどくさい取引先本人：守るもの＝自分が損をしないこと。揚げ足を取ってよい

【ルール】
・各人1つだけ、具体的な指摘をする（120字以内）
・褒めるだけの発言は禁止
・役1と役3は特に、数字・日付など具体性が足りない箇所を見つけたら必ず指摘する

【下書き】
（ここにメール本文を貼る）
```

3. 3人の指摘を全部直してから送ります。

実際に、取引先への値上げ通知メールの下書きで試しました。最初の下書きはこうでした。

```
いつもお世話になっております。誠に恐れ入りますが、諸般の事情により、
来月から料金を少し改定させていただくことになりました。
ご不便をおかけしますが、何卒ご理解のほどよろしくお願いいたします。
```

3人の指摘はこうなりました。

- **厳しい上司**: 「『来月から』『少し』では相手が身構えられません。開始日と改定率を具体的な数字で書いてください。このままでは値上げ交渉の主導権をこちらが放棄しています。」
- **優しい先輩**: 「理由が『諸般の事情』のままだと冷たく見えます。原材料費や配送コストの上昇など、理由を一言添えたほうが関係を守れます。」
- **めんどくさい取引先**: 「理由も言わず値上げされても納得できません。値上げ分でこちらへのサービスは何か変わるんですか。」

指摘に沿って直したのが次の版です。

```
いつもお世話になっております。原材料費・配送コストの上昇に伴い、
誠に恐れ入りますが、2026年10月1日より、料金を5%改定させていただくことになりました。
改定後もこれまで同様のサポート体制で対応させていただきます。
ご不便をおかけしますが、何卒ご理解のほどよろしくお願いいたします。
```

## 3人版と5人版、どちらを使うか

08-09記事の5人会議（顧客代表・現場担当・財務担当・競合の営業・3年後の私）は、企画や大きな意思決定のような「間違えると取り返しがつかない」場面向けでした。今回の3人版は、メール1本・提案文1本のような「今日中に送る小さいもの」を素早く確認する用途です。設定を書く手間が5人の半分程度で済み、3分あれば1周できます。

3人でも指摘が具体的だったのは、役職名だけでなく「守るものを1行」渡したからです。これは08-02の記事（役割名だけでは効果が薄く、自己チェック指示が必要だった検証）と同じ結論で、人数を減らしても効いた条件は変わりませんでした。海外の研究でも、同じAIから作った複数のペルソナは既定のままだと視点の多様性が限定的になり、ペルソナを導入しただけでは改善が出ないという報告があります。役職ラベルより「何を守るか」を具体的に書き込むことが、人数によらず効いているようです。

## つまずきポイント

3人だけに絞ると、設定は1分もかからず、指摘も具体的で送る前チェックとしては十分手応えがありました。

**効かなかったこと**: 軽量版には数字だけをチェックする役がいないため、金額の計算ミスを見逃しました。上の改定版に「月額6,000円から6,200円に、5%の値上げとなります」と数字を加えて同じ3人にもう一度レビューさせたところ、3人とも値上げの伝え方や理由には触れましたが、6,000円から6,200円への値上げは実際には約3.3%であり5%ではないという食い違いには誰も気づきませんでした。3人とも「伝え方」の指摘に集中し、金額の計算そのものは検証していなかったためです。数字を含む文章は、この3人レビューとは別に、金額だけ電卓やコード実行で検算する一手間が必要だと分かりました。

## まとめ

まず今日これだけ: 次に送るメールや提案文を、このプロンプトの3人に見せてから送ってください。ただし金額や日付など数字が入っている場合は、3人の指摘を直したあとにもう一度、数字だけを自分の目か計算で検算してください。
