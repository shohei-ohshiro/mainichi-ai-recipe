会議で経費削減のアイデア出しを頼まれたのに、出てくるのは「残業を減らす」「備品を見直す」といった、誰でも思いつく案ばかり。私も先月、まさにこの壁にぶつかりました。

この記事を読むと、AIに「わざと最悪のアイデア」を出させてから使えるものを1つだけ拾う、という発想の外し方が今日から使えるようになります。

## なぜ「わざと外す」と発想が広がるのか

人間には悪い結果のほうに強く注意が向く性質があり、これを逆手に取って「最悪の案」をあえて考えさせ、そこから裏返して使える発想を拾う手法は、ワークショップの定番技法として以前から知られています（Reverse Brainstorming／Worst Possible Idea法）。良し悪しを判断せずに突拍子もない案を出す段階を挟むことで、普段は評価を気にして出てこない発想まで拾えるのが狙いです。

AI相手でも同じことが起きます。ただし「本音で」程度の頼み方では、AIは無難な範囲から出てくれませんでした（理由は後述します）。

## 手順（所要10分）

### 1. まず普通に聞いてみる（比較用）

```
経費削減のアイデアを10個、思いつく範囲で本音で出してください。
```

### 2. 実現性・法律を無視していいと明言して、最悪の案を頼む

```
これから出すお題について、実現性・予算・法律・常識を一切無視して構いません。
誰も傷つけず笑える範囲で、「最悪のアイデア」を10個出してください。
まともな案は1つも要りません。突拍子もないほど高評価です。

お題：経費削減のアイデア
```

### 3. 出てきた中から1つ選び、裏の課題だけ抜き出させる

```
さきほどの最悪案のうち、○番について教えてください。
1. なぜこれが「最悪」なのか、理由を1行で
2. その理由の裏にある本当の課題は何か、1行で
3. その課題を現実的な範囲で解決する案を1つ、実行手順つきで
```

## 実際に試した内容

手順1では「残業時間を減らす」「紙の使用量を減らす」「会議の回数を減らす」など、経費削減の記事でよく見る案が10個出てきました。すでにまともな案なので、裏返しても新しい発想には広がりません。

手順2で改めて頼むと、「使っていない契約（観葉植物レンタル・宅配水・清掃業者など）を中身を確認せず全部即解約する」という案が出ました。手順3でこれを深掘りすると、「なぜ最悪か」は"必要な契約まで切って業務が止まるリスクがあるから"、その裏にある課題は"そもそも固定費の契約が今どれだけ使われているか誰も棚卸ししていない"でした。ここから、「契約中の固定費を一覧にし、直近3ヶ月の利用実績を横に並べて、使用率が低いものだけを解約候補にする」という、普通に聞いただけでは出てこなかった具体案に落とし込めました。

## つまずきポイント

**効かなかったこと**：手順1のように「本音で」とだけ頼んだ場合、出てくる案は最初から穏当で、裏返しても目新しい発想にはつながりませんでした。「最悪」を引き出すには、実現性や法律を無視していいと明言するところまで踏み込む必要があります。

もう1つ、10個の中から選ぶ基準がないと迷います。「これは会社の中の何かが足りていないサインでは」と一言で説明できる案を選ぶと、手順3の深掘りがスムーズに進みます。

## まとめ、今日からこれだけ

次にアイデア出しで行き詰まったら、いきなり普通に聞くのではなく、「実現性・法律を無視していいので最悪の案を10個」とAIに頼んでみてください。出てきた1つを深掘りするだけで、いつもと違う切り口が見つかります。
