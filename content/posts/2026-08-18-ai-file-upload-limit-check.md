先週、120ページ近い企画書のPDFをそのままAIに貼って要約を頼んだら、後半のセクションにまったく触れてもらえませんでした。ファイルが大きすぎたのかと調べてみると、ChatGPT・Claude・Geminiはそれぞれ違う「ファイルの上限」を持っていて、超えると動きが静かに切り替わる仕組みになっていました。

この記事を読むと、資料をAIに貼る前に3社の上限を確認し、貼っても後半が読み飛ばされる失敗を防げるようになります。

## レシピ本体: 資料を貼る前に3社の上限を確認する（所要時間の目安: 8分）

**手順1（2分）ファイル1つあたりの上限を確認する**

- ChatGPT: 1ファイルは512MBまで。文章やPDFなどのテキスト系ファイルは、中身を最大200万トークン分（AIが文字数を数える単位のようなものです）まで読み込みます。画像は1枚20MBまで。無料（Free）プランはアップロードが1日3ファイルまでという回数制限も別にあります。
- Claude: 1ファイルは30MBまで。それを超えるPDFは、通常のファイル読み込みではなく別の処理（Claude内の実行環境を使った処理）に回されます。
- Gemini: 動画以外のファイルは1つ100MBまで、動画は2GBまで。ただし一度に貼れるファイル数は最大10個までという制限があります。

**手順2（3分）「一度に読める量」も別にあることを確認する**

ファイル1つが上限内でも、AIが一度の会話で処理できる分量（コンテキストウィンドウ）には別の上限があります。

- Claude: 有料プランのOpus 5・Sonnet 5は100万トークン、それより前のモデルは20万トークンです。しかもプロジェクト機能では、資料の量がこの上限に近づくと、全文をそのまま読む方式から必要な部分だけを検索して答える方式（RAGモード）に自動で切り替わる、と公式ヘルプに明記されています。
- ChatGPT: 公式ヘルプで確認できたのは「1ファイルは最大200万トークンまで読み込む」という説明までで、会話全体としての上限は公式ページ上で見つけられませんでした。不確かな数字を書くと正確性に欠けるため、ここでは断定しません。
- Gemini: 有料プランほど扱えるデータ量が増えます。たとえば音声は無料版が合計10分までなのに対し有料版は3時間まで、動画は無料版5分に対し有料版は1時間までという差があります。

**手順3（3分）上限に近そうなら、貼る前に分割する**

資料が大きく上限に近そうな場合は、貼り方を工夫します。

```
この資料は分量が多いので、まず目次か見出し一覧だけ見せてください。
そのあと私が指定する章だけを渡していくので、
章ごとに要点を3行で返してください。
最後にそれまでの要点をつなげて1枚のサマリーにしてください。
```

一度に全部渡すのではなく、目次を先に見せてから章単位で渡すと、AIが後半を読み落としたまま要約してしまう事故を減らせます。

## つまずきポイント

「貼れた」＝「全部読まれた」ではありません。Claudeの公式ヘルプには、資料の量が上限に近づくと全文を読む方式から必要な部分だけを検索して答える方式に自動で切り替わる、と明記されています。上限ギリギリの量を貼ったときほど、実は一部しか見ていない可能性があると考えておいたほうが安全です。

**効かなかったこと**: 「全部読んでください」「省略せずに」と念を押す一文を足しても、上限そのものは変わりません。試しに次のように聞いてみました。

```
今アップロードした資料について、実際にどこまで目を通せましたか？
読めていない範囲があれば、正直に教えてください。
```

これは一定の目安にはなりますが、AI自身の申告を全面的には信用できません（08-17の記事で書いた、モデルは自分の状態を直接検査できず渡された情報の範囲でしか答えられない、という限界と同じ理由です）。念押しの言葉を増やすより、そもそも上限に近づかないよう資料を分けて渡すほうが確実でした。

## まとめ・今日これだけ

次に大きめの資料をAIに貼るときは、貼る前に一度、自分が使っているAIとプランのファイル上限を思い出してください。上限が近そうなら、全部を一度に渡さず、目次を見せてから章ごとに渡すやり方に変えるだけで、後半が読み飛ばされる失敗を防げます。
