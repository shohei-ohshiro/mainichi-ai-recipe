先週、会議メモの要約をAIに頼んだあと、送信ボタンを押す直前に「あ、理由も全部書いてもらわないと」と気づき、指示文の最後に一言だけ追記したことがあります。返ってきた要約を見ると、理由はほとんど省略されたままでした。「ちゃんと書いたのに、なぜ効かなかったんだろう」と思ったのがこの記事のきっかけです。

この記事を読むと、文字数の制限と「全部書いて」という指示が矛盾するとき、指示を書く順番と優先順位の一言でAIの応え方がどれくらい変わるかが、実際に3条件を比較した結果から分かります。

## 矛盾する指示を3つの書き方で試す（所要時間5分）

1. まず、あえて矛盾が起きる題材を用意します。今回は4件の決定事項と理由が書かれた架空の会議メモ（フィクション）を使いました。全部の理由を書くと300字を超える分量です。
2. 同じメモに対して、指示文の「書く順番」だけを変えた3通りを用意します。

条件A（文字数制限が先、あとから追記）:
```
以下の会議メモを300字以内で簡潔にまとめてください。決定事項の要点だけで結構です。

（会議メモ本文）

追記：ただし、決定事項はどれも重要なので、理由も1つも漏らさずすべて書いてください。
```

条件B（「全部書いて」が先、あとから追記）:
```
以下の会議メモをまとめてください。決定事項はどれも重要なので、理由も1つも漏らさずすべて書いてください。

（会議メモ本文）

追記：ただし300字以内で簡潔にまとめてください。
```

条件C（条件Aと同じ順番＋矛盾時の優先順位を明示）:
```
以下の会議メモを300字以内で簡潔にまとめてください。決定事項の要点だけで結構です。

（会議メモ本文）

追記：ただし、決定事項はどれも重要なので、理由も1つも漏らさずすべて書いてください。なお、この指示と文字数制限が矛盾する場合は、文字数制限を優先し、収まらない理由は省略してください。
```

3. 会話履歴を共有しない別々のAI（互いに何も知らない独立したセッション）に、条件A・B・Cをそれぞれ単独で見せます。
4. 返ってきた要約の文字数を自分で数え直し、理由がどこまで書かれているか見比べます（AIの自己申告の文字数は誤差があるため、自分でも数えました）。

実際に試した結果です。条件A（文字数制限が先）は135字で、4件の決定事項には触れていたものの、理由はどれも数語に圧縮されていました。条件B（「全部書いて」が先）は237字で、4件それぞれの理由がほぼそのままの詳しさで書かれていました。条件C（優先順位を明示）は233字で、条件Bとほぼ同じ密度で理由が書かれていました。同じ「4件・理由を全部」という内容でも、指示の書き方だけで情報量が135字から237字まで、約1.8倍変わったことになります。

## つまずきポイント

私は当初、条件Cのように「矛盾したら文字数制限を優先し、理由は省略してよい」と明示すれば、条件Aよりもさらに短く、省略に振り切った要約が返ってくると予想していました。実際には逆で、条件Cは条件Aよりずっと情報量が多く、条件Bに近い書き方になりました。

**効かなかったこと（今回、予想が外れた点）**: 「矛盾時は文字数を優先して省略してよい」という許可を与えたつもりの一言が、省略を後押しするどころか、むしろ情報を残す方向に働いたように見えました。指示の最後に置いた一文がそのまま弱く扱われるわけではなく、その一文の中身（省略していいという許可なのか、全部書けという念押しなのか)によっても結果が変わる、という単純な「あとの指示ほど軽く見られる」では説明しきれない挙動でした。

もう1つ、この検証は各条件1回ずつ、架空の会議メモ1本だけで行っています。何度も繰り返した時に同じ傾向が出るか、内容や分量が違うメモでも同じになるかは確認できていません。使ったのはClaude単体で、ChatGPT・Geminiで同じ傾向になるとは断定できません（技術的な背景はZenn版で詳しく書きました）。また、AIが返す文字数の自己申告は本文とずれることがあるため、今回は自分で数え直した数字を採用しています。

この頼み方は、会議メモの要約に限った話ではありません。企画書の骨子を「3枚以内で」と頼んだあとに「でも競合比較は絶対落とさないで」と追記したり、スライドの構成案を「シンプルに」と頼んだあとに「数字の根拠は全部残して」と付け足したり——似た矛盾は、資料作成のいろいろな場面で起こりがちです。今回の結果を踏まえると、こうした「あとから気づいた条件」は、追記せずに最初の指示文へ書き直してから送る方が、実際に反映される可能性が高そうです。

## まとめ

まず今日これだけ：あとから「あ、それと〜も」と条件を追記するのをやめて、矛盾しそうな条件は最初から1つの指示文に並べて書いてみてください。それだけで、AIが実際に踏み込んで応える範囲が変わることがあります。優先順位の一言を足すかどうかは、今回のように結果を見ながら自分の用途で確かめてみるのがおすすめです。
