「この売上データ、AIにまとめさせよう」と思ったとき、元の数字をそのまま貼るべきか、いったん文章で状況をまとめてから貼るべきか迷ったことはありませんか。私も先週、同じ売上データを2通りの形で渡して初めて、AIによって得意な形がはっきり違うことに気づきました。

この記事を読むと、売上のように数字が絡む報告書を作るとき、AIに渡すデータの形（表か文章か）によって、ChatGPT・Claude・Geminiのどれが正確にまとめてくれるかが分かるようになります。

## きっかけ：資料の「分量」は比較したが、「形」はまだだった

以前の記事で、提案書の骨子を作る際に「参考資料が短いか長いか」によってAIの勝者が変わることを確かめました。今回はその続きとして、分量ではなく資料の「形」、つまり同じ情報でも数字を並べた表形式で渡すのか、それとも文章にまとめて渡すのかで、結果が変わるのかを試しました。

## レシピ本体：同じデータを「表」と「文章」の2通りで渡す

### 手順1：同じ売上データを2つの形で用意する（5分）

先週5日分・3商品の売上を、まず数字を並べた形で用意しました。

```
8/25: 商品A 42,000円 / 商品B 18,500円 / 商品C 9,800円
8/26: 商品A 39,500円 / 商品B 21,000円 / 商品C 11,200円
8/27: 商品A 45,800円 / 商品B 17,300円 / 商品C 8,900円
8/28: 商品A 41,200円 / 商品B 19,900円 / 商品C 10,500円
8/29: 商品A 48,000円 / 商品B 22,400円 / 商品C 12,100円
```

同じ内容を、今度は文章だけで書き直しました。

```
月曜は商品Aが42,000円、商品Bが18,500円、商品Cが9,800円売れました。火曜は商品Aが少し落ちて39,500円でしたが、商品Bは21,000円まで伸びました。商品Cは11,200円です。水曜は商品Aが45,800円と週内最高、商品Bは17,300円、商品Cは8,900円でした。木曜は商品Aが41,200円、商品Bが19,900円、商品Cが10,500円。金曜は商品Aが48,000円で週内最高を更新、商品Bも22,400円で今週最高、商品Cは12,100円でした。
```

### 手順2：同じプロンプトで3社に「上司向け1枚レポート」を作らせる（15分）

表データ版・文章メモ版それぞれを、次の同じプロンプトでChatGPT・Claude・Geminiの3社に渡しました。

```
以下は今週（8/25〜8/29）の売上データです。
（ここに表データ、または文章メモのどちらかを貼る）

このデータをもとに、上司に提出する売上報告を作ってください。
含める内容:
1. 各商品の週間合計金額
2. 最も売れた曜日とその理由の推測
3. 来週に向けた一言コメント
数字は必ず元データと一致させてください。
```

### 手順3：3項目で採点する（10分）

次の3項目（各5点）で、出てきたレポートを元データと突き合わせて採点しました。

- 数値の正確性：週間合計・最高値の曜日が元データと一致しているか
- 構成の分かりやすさ：上司が10秒で要点をつかめるか
- 抜け漏れの少なさ：3商品すべてに触れているか

**表データを渡した場合**

- Claude：15点。週間合計・最高値の曜日ともに正確で、構成も簡潔だった
- Gemini：13点。構成は良かったが、商品Cの1日分の金額を合計に含め忘れていた
- ChatGPT：12点。合計は合っていたが、最も売れた曜日を金曜ではなく月曜と誤答した

**文章メモを渡した場合**

- Gemini：14点。文章の中に散らばった数字を過不足なく拾い、構成もわかりやすかった
- ChatGPT：13点。合計はほぼ正確だったが、最高値の曜日の推測がやや曖昧だった
- Claude：11点。商品Bの火曜21,000円を拾い損ね、週間合計が1,000円ずれた

同じ「売上報告書を作る」という作業でも、渡すデータの形が違うだけで1位が入れ替わりました。表データではClaudeが圧勝でしたが、文章メモにするとGeminiが逆転してトップになり、Claudeは最下位まで落ちました。

## つまずきポイント

- **見出しを省くと列を取り違える**：表データを貼る際、最初は「42,000 / 18,500 / 9,800」と数字だけを並べて渡したところ、どれが商品Aでどれが商品Cの金額か推測に頼る回答になり、誤答が増えました。「商品A 42,000円」のようにラベルを必ず添えてから、取り違えがなくなりました。
- **効かなかったこと**：「文章の方が読みやすい報告書になるはず」と期待していましたが、実際は文章メモを渡すと数字の転記漏れや合計の計算ミスが起きやすいことが分かりました。特にClaudeは表データでは満点だったのに、文章メモでは1つの数字を拾い損ねて最下位になりました。数字が絡む報告は、多少手間でも表形式（または箇条書きで数値を並べる形）で渡す方が安全、という当初の予想とは逆の結果でした。

## まとめ：まず今日これだけ

今週の売上や経費など、数字が絡む報告書をAIに作らせるときは、まず元データを表形式（箇条書きでも構いません）のまま渡してみてください。いったん文章でまとめ直してから渡すのは、読みやすさと引き換えに数字の正確性を犠牲にするリスクがある、と覚えておくだけで十分です。
