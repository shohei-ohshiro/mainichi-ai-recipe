会議メモをAIに要約してもらうとき、「雑談や世間話は絶対に含めないでください」と念を押したのに、できあがった要約にその雑談の内容がそのまま書かれていた、ということはありませんか。私も先週、社内共有用の議事録でまさにこれをやられました。「入れるな」と言った話題が、要約の中に「雑談（〇〇の話）がありました」という形で結局登場していたのです。

この記事を読むと、AIへの「〜しないで」という禁止形の指示がなぜ逆効果になりやすいかが分かり、同じ会議メモで実際に3パターンのプロンプトを試した結果を見ながら、今日から効く言い換え方を1つ持ち帰れます。

## レシピ本体：同じメモ、3つのプロンプトで結果を比較する（所要時間の目安：5分）

素材にしたのは、こんな短い会議メモです。

```
14時開始。売上速報の共有と、来月のキャンペーン案の相談。
ところで田中さん髪切りました?とても似合ってますね。
キャンペーンの予算は50万円で決定。担当は佐藤さん。
次回は来週水曜。最近暑いですね、冷房が効きすぎて肌寒いくらいです。
```

**パターン1（禁止形・うまくいかなかった方）**

```
以下の会議メモを箇条書きで要約してください。
ただし、雑談や世間話は絶対に含めないでください。

(ここに上のメモを貼る)
```

結果は次のような要約でした。

- 売上速報の共有とキャンペーン案の相談を実施
- 雑談（髪型の話・天気の話）がありました
- キャンペーンの予算は50万円で決定、担当は佐藤さん
- 次回は来週水曜

「含めないで」と頼んだ雑談が、"雑談があった"という形でしっかり名指しされて残っています。禁止した話題ほど、AIはそれに触れて「ちゃんと除外しました」と申告したがる、という意外な挙動でした。

**パターン2（言い換え・含めるものだけを指定）**

除外を指示するのをやめて、残したいものだけを指定する形に言い換えます。

```
以下の会議メモから、決定事項・担当者・次回予定だけを箇条書きで抜き出してください。
それ以外の情報は出力に一切書きません。

(ここに上のメモを貼る)
```

結果はこうなりました。

- 予算: 50万円で決定
- 担当: 佐藤さん
- 次回: 来週水曜

雑談への言及そのものが消え、狙った3項目だけがきれいに残りました。「除外」ではなく「何を出力に含めるか」を定義に変えただけで結果が変わっています。

**パターン3（言い換え・長いメモ向けの2段階版）**

メモが長くなり除外したい話題が増えるほど、パターン2の一発指定だけでは判定漏れが出やすくなります。その場合は分類と出力を2段階に分けます。

```
次の手順で処理してください。
1. 会議メモを1行ずつ「決定事項」か「雑談」のどちらかに分類する
2. 「決定事項」に分類した行だけを箇条書きで出力する
3. 「雑談」に分類した行の内容には一切触れない

(ここに上のメモを貼る)
```

こちらもパターン2と同じ結果になり、行数が多いメモでも判定基準がぶれにくくなりました。

## つまずきポイント

- **効かなかったこと**：パターン1がうまくいかなかったとき、「絶対に」「何があっても」と禁止の言葉を強めて再送してみましたが、結果は変わらず、むしろ「雑談（髪型・天気の話題）は完全に除外しました」と、除外した内容をより丁寧に説明してくる回になりました。禁止を強調するほど良くなる、という直感は今回は外れました。
- 除外したい話題が1つだけの短いメモならパターン1でもたまたま消えることがあり、毎回同じ結果になるとは限りません。話題が増えるほど再現性が落ちるため、最初から「含めるものを定義する」書き方に統一しておくほうが安定します。

## まとめ：まず今日これだけ

今使っている要約・整形系のプロンプトに「〜しないで」「〜を含めないで」という一文があれば、それを「〜だけを出力してください」という言い方に1つだけ書き換えて試してください。それだけで、禁止したはずの内容が出力に残る事故を減らせます。
